# Speckit Tasks Command

Break down the implementation plan into actionable tasks.

## Usage

```
$speckit-tasks
```

## Guidelines

1. Read the plan from `specs/[current-feature]/plan.md`
2. Use the tasks template at `.specify/templates/tasks-template.md`
3. Create `specs/[feature]/tasks.md`
4. Include dependency-ordered tasks with clear acceptance criteria
