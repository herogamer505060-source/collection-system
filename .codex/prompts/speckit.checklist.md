# Speckit Checklist Command

Verify implementation against the specification and plan.

## Usage

```
$speckit-checklist
```

## Guidelines

1. Read the spec from `specs/[current-feature]/spec.md`
2. Read the plan from `specs/[current-feature]/plan.md`
3. Read the tasks from `specs/[current-feature]/tasks.md`
4. Create a checklist verifying each requirement is met
5. Mark completed items and identify gaps
