# Speckit Plan Command

Create a technical implementation plan for the current feature specification.

## Usage

```
$speckit-plan [technology choices...]
```

## Guidelines

1. Read the feature spec from `specs/[current-feature]/spec.md`
2. Read the plan template at `.specify/templates/plan-template.md`
3. Create `specs/[feature]/plan.md` with:
   - Technology choices
   - Project structure
   - API design
   - Data model
   - Implementation approach
