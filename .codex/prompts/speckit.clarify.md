# Speckit Clarify Command

Clarify requirements and resolve ambiguities in the current specification.

## Usage

```
$speckit-clarify [question]
```

## Guidelines

1. Review the current feature spec and plan
2. Identify ambiguities or gaps
3. Ask clarifying questions to the user
4. Update the spec with clarified requirements
