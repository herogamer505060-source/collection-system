# Speckit Specify Command

Create a feature specification in the `specs/` directory.

## Usage

```
$speckit-specify [feature description]
```

## Guidelines

1. Read the constitution at `.specify/memory/constitution.md`
2. Use the spec template at `.specify/templates/spec-template.md`
3. Create the spec in `specs/[feature-name]/spec.md`
4. Include what/why, user stories, requirements, and acceptance criteria
