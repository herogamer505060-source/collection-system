# Speckit Commands

This project uses GitHub SpecKit for spec-driven development.

## Available Commands

| Command | Description |
|---------|-------------|
| `$speckit-constitution` | Create/update project constitution |
| `$speckit-specify` | Create feature specification |
| `$speckit-plan` | Create technical implementation plan |
| `$speckit-tasks` | Generate task list |
| `$speckit-implement` | Execute implementation |
| `$speckit-checklist` | Verify implementation |
| `$speckit-clarify` | Clarify requirements |
| `$speckit-analyze` | Analyze codebase |

## Workflow

1. `$speckit-constitution` - Set project principles
2. `$speckit-specify` - Define what to build
3. `$speckit-plan` - Design the approach
4. `$speckit-tasks` - Break into tasks
5. `$speckit-implement` - Build it
6. `$speckit-checklist` - Verify it
