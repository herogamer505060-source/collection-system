# Speckit Specify Skill

## Description
Create a feature specification documenting what to build and why.

## Usage
```
$speckit-specify [feature description]
```

## Steps

1. Read constitution from `.specify/memory/constitution.md`
2. Create feature directory `specs/[feature-name]/`
3. Generate `spec.md` using `.specify/templates/spec-template.md`
4. Include: Overview, User Stories, Requirements, Acceptance Criteria
5. Create `requirements.md` with detailed requirements
6. Create `checklists/requirements.md` with verification checklist

## Output
Create `specs/[feature-name]/spec.md` and supporting files.
