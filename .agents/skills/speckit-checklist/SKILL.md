# Speckit Checklist Skill

## Description
Verify implementation against specification and plan.

## Usage
```
$speckit-checklist
```

## Steps

1. Read spec from `specs/[feature-name]/spec.md`
2. Read plan from `specs/[feature-name]/plan.md`
3. Read tasks from `specs/[feature-name]/tasks.md`
4. Verify each requirement is implemented
5. Verify each task is completed
6. Identify any gaps
7. Create verification report

## Output
Create checklist report identifying what's done and what's missing.
